# In-Game Timer

Minecraft Java Edition 26.2용 Fabric 모드입니다. Fabric Loader 0.19.5 이상과 Minecraft 26.2용 Fabric API 0.160.0 이상이 필요합니다.

| 명령어 | 동작 |
| --- | --- |
| `/igt game toggle` · `/igt real toggle` | 해당 시계를 시작, 정지, 재개 |
| `/igt game reset` · `/igt real reset` | 해당 시계를 초기화하고 정지 |
| `/igt game settings` · `/igt real settings` | 해당 시계 설정 열기 |

`start`, `stop`, `resume` 명령으로 각 동작을 직접 실행할 수도 있습니다. 기존 `/igt` 명령은 게임 기준 시계에 적용됩니다.

단축키는 기본적으로 미할당입니다. 각 시계의 설정에서 **단축키**를 열고 시작·정지·재개, 초기화, 설정 열기, HUD 표시·숨기기에 원하는 키를 지정하세요. `Shift+F`처럼 보조 키를 누른 채 다른 키를 누르면 조합으로 저장됩니다. 키 입력 대기 중에 `Esc`를 누르면 해제됩니다.

**두 HUD 표시 / 숨기기**는 양쪽 설정 화면에서 지정할 수 있는 공통 단축키입니다. HUD가 하나라도 보이면 둘 다 숨기고, 둘 다 숨겨져 있으면 함께 표시합니다.

`T`를 눌러 채팅을 열면 각 HUD에서 시작·정지·재개, 초기화, 설정을 조작할 수 있습니다. 각 본문을 마우스로 드래그해 위치를 따로 저장할 수 있습니다. HUD가 꺼져 있을 때는 해당 시계의 설정 명령으로 다시 켤 수 있습니다.

설정 화면 상단에서 시계를 선택합니다. HUD 표시 여부, 불투명도(0~100%), 게임틱·레드스톤틱·시간 표시 여부, 스톱워치·카운트다운 모드와 길이를 시계별로 바꿀 수 있습니다. 두 HUD를 동시에 표시할 수 있습니다. 모드나 카운트다운 길이를 바꾸면 해당 시계의 측정값이 초기화됩니다. 기존 설정은 게임 기준 시계에 적용됩니다.

HUD에는 `game tick`, `redstone tick`, `real time`을 표시합니다. **최소화**를 켜면 해당 시계의 제목과 항목 이름을 숨기고 선택한 값만 표시합니다.

- **게임 기준 시계**는 서버가 진행한 실제 월드 틱을 셉니다. 싱글플레이 일시정지와 `/tick freeze` 중에는 세 표시가 모두 멈춥니다. `/tick step`으로 진행된 틱을 세며, `/tick rate`에 따라 표시가 진행되는 속도가 달라집니다.
- **현실 기준 시계**는 단조 시계에서 경과 시간을 잽니다. 실제 1초를 20게임틱에 해당하는 값으로 표시하므로 게임을 멈춰도 세 표시가 모두 진행됩니다.
- 두 시계에서 20게임틱은 표시 시간 1초, 2게임틱은 1레드스톤틱입니다. 레드스톤틱은 실행 중 정수로 표시하고, 시계를 정지했을 때 홀수 게임틱이면 `.5`를 표시합니다. 카운트다운은 각 시계의 기준으로 0에 도달하면 종료됩니다.

싱글플레이에서는 클라이언트에만 설치하면 됩니다. 멀티플레이에서 게임 기준 시계를 사용하려면 서버에도 모드가 필요합니다. 원격 서버의 틱 표시에는 네트워크 지연이 반영됩니다. 현실 기준 시계는 서버 모드 없이 사용할 수 있습니다. 접속을 종료하면 두 시계의 측정값이 초기화됩니다.

## 빌드

JDK 25로 Windows에서는 `gradlew.bat build`, macOS와 Linux에서는 `./gradlew build`를 실행하세요. 설치용 JAR은 `build/libs/in-game-timer-1.5.0.jar`에 생성됩니다.
